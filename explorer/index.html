What you are NOT seeing: who paid whom, how much, which note was spent. The pool publishes commitments, nullifiers and one running total — compliance visibility exists, but only as scoped, holder-initiated disclosure. No master key exists structurally.

Every vote is hash-based (LMS/HSS over SHAKE-256) under an SLH-DSA root — the consensus itself is post-quantum, not just the wallets. Epoch badges climb when a validator rotates its signing tree — automatic since v0.10.5; on testnet-1 all four seats rotated unattended on 2026-09-03 (heights 11,584–11,595). The external row counts nodes that joined via the public join kit and independently verify the chain from block 1. These validators run on Google Cloud; the prover lives elsewhere entirely. Issuer-controlled, chain-enforced. An issuer registers an asset under an id only it can claim (H(issuer ‖ symbol)), then mints, burns, freezes an account or pauses the asset under a policy fixed at registration. Supply and burns sit inside the state commitment; conserved ✓ is this node's own check that Σ balances + escrow + pool = supply − burned. Every mint here is issuer-signed — attested (reserve-backed) minting is designed, not built.
